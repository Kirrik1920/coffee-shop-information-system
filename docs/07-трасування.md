# 7. Трасування вимог (лекція 11)

Таблиці показують, що кожна потреба користувача реалізована функцією системи та перевірена тестом.

## Потреби користувачів

| № | Потреба | Хто |
|---|---|---|
| П-1 | Швидко оформити замовлення | Клієнт (касир) |
| П-2 | Отримувати замовлення по черзі | Бариста |
| П-3 | Не втрачати замовлення під час збоїв | Власник |
| П-4 | Бачити стан роботи та бази даних | Власник |
| П-5 | Дізнаватись про проблеми | Власник, адміністратор |
| П-6 | Мати записи про виконані замовлення | Власник |
| П-7 | Допускати до системи лише своїх працівників | Власник, адміністратор |
| П-8 | Швидко знаходити причину проблеми | Адміністратор |

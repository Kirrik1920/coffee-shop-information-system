# 3. Тестування

Перевірка зв'язків між сервісами та даними. Усі тести виконано на чистому запуску 9 листопада 2026 року в Docker Desktop на Windows 10.

| № | Що перевіряємо | Дія | Очікування | Результат |
|---|---|---|---|---|
| Т-1 | Меню | `GET /menu` | 5 напоїв із цінами | пройдено |
| Т-2 | Правильне замовлення | `POST /orders` з напоєм `latte` | код 202 | пройдено |
| Т-3 | Напою немає в меню | `POST /orders` з напоєм `vodka` | код 400 | пройдено |
| Т-4 | Неправильна кількість | `quantity: 0` | код 400 | пройдено |
| Т-5 | Некоректний JSON | тіло `x` | код 400 | пройдено |
| Т-6 | Повний ланцюжок | 6 замовлень | у базі 6, черга 0 | пройдено |
| Т-7 | Збір метрик | Prometheus, цілі | усі 3 цілі `up = 1` | пройдено |
| Т-8 | Незалежність сервісів | зупинити бариста, надіслати 15 замовлень | усі прийняті, у черзі 15 | пройдено |
| Т-9 | Алерти | бариста зупинений понад 30 с | `OrdersQueueTooLong` і `BaristaServiceDown` у стані firing, обидва в Alertmanager | пройдено |
| Т-10 | Відновлення | запустити бариста | черга 0, у базі 21, алерти зникли | пройдено |
| Т-11 | Повторна доставка | опублікувати одне повідомлення двічі | у базі один запис, `duplicate_total = 1` | пройдено |
| Т-12 | Зіпсоване повідомлення | опублікувати `not json` | `failed_total = 1`, у черзі `orders.invalid` 1, алерт `InvalidOrdersDetected` у стані firing | пройдено |
| Т-13 | Надійність брокера | 3 замовлення в черзі, перезапустити RabbitMQ | після перезапуску 3 в черзі, усі виконані, нове замовлення приймається | пройдено |
| Т-14 | Дашборд | відкрити Grafana | 9 панелей, джерело даних працює | пройдено |
| Т-15 | Лічильник після перезапусків | перезапуски бариста й брокера | за період 25, у базі 25 | пройдено |
| Т-16 | Права `order_service` | спробувати читати чергу й створити нову | доступ заборонено | пройдено |
| Т-17 | Права `barista_service`, вхід `guest` | спробувати публікувати, створити чергу, увійти як `guest` | доступ заборонено | пройдено |
| Т-18 | Virtual host | список vhost, вхід у `/` | є лише `coffee`, доступ до `/` заборонено | пройдено |

Не перевірялось: надсилання листів через Gmail, бо для цього потрібен твій пароль застосунку.
Навантажувальне тестування теж не проводилось.

Рівні тестування за лекцією 3: Т-1…Т-5 перевіряють один сервіс (висхідне тестування), Т-6…Т-18 перевіряють взаємодію сервісів (інтеграційне тестування).

Зв'язок тестів із вимогами наведено в `07-трасування.md`.
